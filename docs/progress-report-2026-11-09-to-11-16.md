# Rhythm Football 制作進捗報告（2026年11月9日〜11月16日）

- **研究テーマ**：N1分析を用いたペルソナ特化型リズムゲームの制作
- **作品名**：Rhythm Football（サッカー × リズムゲーム）
- **制作環境**：Unity 6 / C# / URP、Android向け横画面を想定
- **対象期間**：2026年11月9日（月）〜11月15日（日）、11月16日（月）
- **記録の位置付け**：ゼミの進捗報告用。Unity Editorでの制作状況と今後の計画を整理する。GitHub上のWeb版の変更履歴と、ローカルで進めているUnity版の作業は区別する。

> **進捗の表記**：「実装・確認済み」は制作者がUnityで動作できたと報告したもの。「準備済み・未検証」はスクリプトや方針を用意した段階であり、Unity Editor / Android実機での動作成功を意味しない。

## 1. 先週の進捗：11月9日（月）〜15日（日）

### 今週の目標
Unity版の基本操作・判定に加え、選手の動きを導入して、サッカーゲームとしての体験と見た目の完成度を高める。

### 実際に進めたこと
1. **人型3Dキャラクターの導入**  
   Capsuleの仮プレイヤーから、Mixamoの人型モデルを使った表現へ移行。フィールド上で足が地面に合うよう位置を調整した。
2. **アニメーション素材とAnimatorの設定**  
   Mixamoから待機（Idle）・キック（Kick）・ヘディング（Head）のアニメーションを取り込み、Humanoid / AvatarおよびAnimator Controllerを設定。Idleの再生をUnity上で確認した。
3. **プレイヤー操作との連動を進めた**  
   KICK / HEADの入力に応じて対応する動作へ切り替え、再び待機動作に戻す処理を作成・調整した。入力連動の動作確認は11月16日時点で完了している。
4. **ゲーム体験の課題を整理**  
   単にPERFECT / GOOD / MISSを表示するだけでは、選手がボールを打ち返す手応えが十分でないと判断。シュートとゴール演出を次の改善対象とした。

### 先週の到達点
- 人型キャラクターとアニメーションの基盤を構築した。
- 見た目だけの仮3Dゲームから、選手の動作が分かるゲームへ改善を進めた。
- 次の制作課題を「操作後のボールの動きと得点時の視覚演出」に絞った。

### 仕様の見直し：音楽ゲームとして成立させる
現状の一定間隔で飛ぶボールへの入力は、リズムゲームというよりタイミングアクションゲームに近いという課題を確認した。そこで、研究当初の「音楽ゲーム × サッカー」を維持するため、次の実装方針を決定した。

- 仮の**120 BPM**音源から始め、音楽の拍とボールの到達タイミングを同期する。
- 一定間隔ではなく、**拍・裏拍・休符**を組み合わせた複数のパターンをランダムに選び、球出しを変化させる。
- KICK / HEADの種類も変化させる。ただしプレイヤーが対応できない間隔は避ける。
- ボールが飛行中に次のボールが出る場面に対応するため、**複数ボール管理**へ拡張する。
- 判定はフレーム数だけに依存せず、音楽上の目標時刻と入力時刻との差を基準にする。
- オリジナル楽曲（約60秒、120 BPM、スタジアム×EDMの方向性）の制作を検討・準備する。
- 音声ミドルウェア **CRIWARE（CRI ADX）**は必須とは決めず、Unity標準の音声同期機能で試作し、Android実機で問題があれば採用を検討する。

### 本日時点で「未完了」の内容
- 音楽同期・ランダム譜面・複数ボールに対応する**改修版コードは準備したが、Unityへの導入と動作確認は未実施**。
- オリジナル楽曲はまだ完成していない。
- Android APKのビルド、実機でのタッチ操作・音声遅延検証は未確認。

## 3. N1分析とのつながり

2026年10月19日の第1回試遊では、操作方法の分かりやすさとボールのタイミング判断がそれぞれ **2/5**、爽快感と楽しさがそれぞれ **4/5** だった。また、PERFECT / GOOD / MISSの判定表示は肯定的に受け止められ、ボールとスコア表示が重なる点は課題として挙がった。

今回の改善では、次を意識した。

- **操作の伝わりやすさ**：人型選手のキック／ヘディングと入力を対応させる。
- **フィードバックと爽快感**：判定に応じたシュートの動き、ゴール裏の紙吹雪を追加する。
- **画面の視認性**：文字だけの表示から色分けされたHUDへ変更する。
- **テーマとの一貫性**：音楽に合わせてボールを打つ仕組みを導入し、リズムゲームとして再評価する。

これらは制作者側の改善仮説であり、**N1対象者の評価が上がったことはまだ確認していない**。週末の再テストで検証する。
